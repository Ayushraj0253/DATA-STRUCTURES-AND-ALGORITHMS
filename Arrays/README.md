# Arrays

An array is a linear data structure that stores elements of the same data type in contiguous memory locations.

## Key Concepts
- **Linear Scan & Two Pointers**: Efficient traversal from both ends or sliding boundaries.
- **Binary Search**: Fast searching on sorted arrays ($O(\log n)$).
- **Prefix Sums & Sliding Window**: Techniques for fast range queries and subarray computations.
