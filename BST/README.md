# Binary Search Tree (BST)

Node-based binary tree data structure where the key in each node is greater than all keys in its left subtree and less than all keys in its right subtree.

## Key Concepts
- **BST Properties**: In-order traversal yields elements in strictly ascending sorted order.
- **Operations**: Search, Insertion, Deletion in $O(h)$ time ($O(\log n)$ average, $O(n)$ worst-case).
- **Advanced BSTs**: Lowest Common Ancestor (LCA), Validate BST, BST Iterator.
