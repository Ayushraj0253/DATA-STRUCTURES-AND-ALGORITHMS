# Backtracking

Algorithmic technique for solving problems recursively by trying to build a solution incrementally, piece by piece, removing solutions that fail to satisfy constraints.

## Key Concepts
- **State-Space Tree Exploration**: Generating permutations, combinations, and power sets.
- **Pruning**: Cutting invalid search branches early to optimize performance.
- **Classic Problems**: N-Queens, Sudoku Solver, Word Search, Rat in a Maze.
