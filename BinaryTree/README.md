# Binary Tree

Hierarchical data structure in which each node has at most two children, referred to as the left child and right child.

## Key Concepts
- **Traversals**: Pre-order, In-order, Post-order (DFS), and Level-order (BFS).
- **Properties**: Height, Depth, Diameter, Maximum Path Sum, Symmetry.
- **Tree Views**: Top View, Bottom View, Left View, Right View.
