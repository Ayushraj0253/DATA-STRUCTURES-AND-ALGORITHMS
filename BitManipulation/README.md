# Bit Manipulation

Technique of performing operations on one or more bit patterns or binary numerals at the level of individual bits.

## Key Concepts
- **Bitwise Operators**: `AND (&)`, `OR (|)`, `XOR (^)`, `NOT (~)`, `Left Shift (<<)`, `Right Shift (>>)`, `Unsigned Right Shift (>>>)`.
- **Common Bit Tricks**:
  - Check odd/even: `(n & 1) != 0`
  - Check power of 2: `n > 0 && (n & (n - 1)) == 0`
  - Get / Set / Clear / Toggle bit at position $i$
  - Isolate lowest set bit: `n & (-n)`
- **Standard Problems**: Single Number (XOR), Counting Set Bits (Brian Kernighan's Algorithm), Subsets Generation using Bitmask.
