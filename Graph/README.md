# Graph

Non-linear data structure consisting of vertices (nodes) and edges connecting pairs of vertices.

## Key Concepts
- **Representations**: Adjacency Matrix and Adjacency List.
- **Traversals**: Breadth-First Search (BFS) and Depth-First Search (DFS).
- **Shortest Paths**: Dijkstra's Algorithm, Bellman-Ford, Floyd-Warshall.
- **Minimum Spanning Tree (MST)**: Prim's Algorithm and Kruskal's Algorithm (with Disjoint Set Union / DSU).
- **Directed Graphs**: Topological Sorting (Kahn's algorithm & DFS), Cycle Detection.
