# Hashing

Technique of mapping large keys to smaller indices using hash functions for $O(1)$ average time lookups, insertions, and deletions.

## Key Concepts
- **HashMap & HashSet**: Direct lookup, frequency counting, deduplication.
- **Collision Resolution**: Chaining and Open Addressing.
- **Prefix Sum + Hashing**: Subarray sum equals K, longest subarray with target sum.
