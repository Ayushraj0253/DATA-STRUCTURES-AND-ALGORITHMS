# Heap

Specialized tree-based data structure satisfying the heap property (Max-Heap or Min-Heap).

## Key Concepts
- **Binary Heap**: Array representation where parent is at index $i$, children at $2i+1$ and $2i+2$.
- **Heapify & Build Heap**: Sift-down and sift-up operations ($O(n)$ build heap).
- **Heap Sort**: In-place sorting with $O(n \log n)$ time.
