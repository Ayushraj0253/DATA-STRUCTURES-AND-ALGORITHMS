# Linked List

Linear data structure where elements are stored in nodes, each pointing to the next (and previous in doubly linked lists).

## Key Concepts
- **Singly & Doubly Linked Lists**: Insertion, deletion, reversal.
- **Fast & Slow Pointer Technique**: Cycle detection (Floyd's algorithm), middle of list.
- **Merge & Sort**: Merge two sorted lists, merge k-sorted lists.
