# Priority Queue

Abstract data type similar to a regular queue or stack, but where each element has an associated priority.

## Key Concepts
- **Java `PriorityQueue`**: Min-heap default; custom Comparators for Max-heap or compound ordering.
- **Top-K Problems**: K largest/smallest elements in streams.
- **Median in Data Stream**: Two heaps technique (Max-Heap + Min-Heap).
