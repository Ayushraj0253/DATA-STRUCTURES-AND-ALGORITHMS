# Searching Algorithms

Algorithms designed to retrieve elements or verify their existence within data structures or search spaces.

## Key Concepts
- **Linear Search**: Sequential scan — $O(n)$ time.
- **Binary Search**: Divide-and-conquer on sorted collections — $O(\log n)$ time.
- **Binary Search on Answer**: Peak finding, square root, allocation/optimization problems.
