# Sorting Algorithms

Algorithms that rearrange a given array or list elements according to a comparison operator on the elements.

## Key Concepts
- **Comparison Sorts**:
  - Bubble Sort, Selection Sort, Insertion Sort: $O(n^2)$
  - Merge Sort, Quick Sort, Heap Sort: $O(n \log n)$
- **Non-Comparison Sorts**: Counting Sort, Radix Sort, Bucket Sort: $O(n + k)$
- **Stability & In-place Characteristics**: Preserving relative order and memory overhead.
