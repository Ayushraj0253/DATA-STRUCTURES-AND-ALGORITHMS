# Stack

Last-In-First-Out (LIFO) data structure supporting push, pop, and peek operations in $O(1)$ time.

## Key Concepts
- **Standard Operations**: Array and Linked-List based stack implementations.
- **Monotonic Stack**: Next greater element, daily temperatures, largest rectangle in histogram.
- **Expression Evaluation**: Valid parentheses, infix to postfix, reverse Polish notation.
