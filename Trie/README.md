# Trie (Prefix Tree)

Tree-like data structure used to efficiently store and retrieve keys in a dataset of strings.

## Key Concepts
- **Node Structure**: Array of children pointers (size 26 for English lowercase) and an `isEndOfWord` boolean flag.
- **Core Operations**: Insert ($O(L)$), Search ($O(L)$), StartsWith prefix match ($O(L)$), where $L$ is word length.
- **Advanced Applications**: Auto-complete, Spell Checker, Maximum XOR Pair (Bitwise Trie).
